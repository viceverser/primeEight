# PrimeEight GUI assets

These are the currently approved visual assets for the PrimeEight GUI prototype.

- `GUI/assets/PrimeEight_Original_Ape8_Logo.svg`: user's original vector ape/8 logo. Do not modify its paths, proportions or intentional sharp arrow details.
- `GUI/reference/PrimeEight_GUI_Approved_Reference.png`: approved flat GUI visual reference. This is NOT intended as a bitmap UI background; build the controls and panel as native scalable graphics.

No fonts, alternate wordmarks, knob sprites, or invented control graphics are included. Those should be selected/implemented separately, subject to approval.

Upload the contents of this ZIP into the repository root, retaining folder paths. This ZIP is not a compiled plugin or complete GUI source implementation.
